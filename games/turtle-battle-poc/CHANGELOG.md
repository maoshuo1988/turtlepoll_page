# Changelog

## v1.0 — 2026-05-30 (首发)

### 核心机制
- 28 只龟全套技能 + 被动 + 形态切换 (双头/熔岩/赛博)
- 44 件常驻装备 + 12 商店增益 + 8 消耗品, 全部行为已对原版 JS audit
- 宝箱龟 15 件专属装备池 + 财宝进度系统 + 5 件上限
- 缩头随从按主人等级抽技能 (1 基础 + 2 解锁池, 30% 概率含被动)
- 龟壳「复制」对 27 种 enemy 技能黑名单 + SELF/ALLY/AOE 智能 target

### 本版修复
- 重击锤 ATK 加成 (4%×maxHp×件数) 收口进 recalc 链
- 怒火药水 / 全队增益 buff 立即生效 (原要等下回合)
- 必中标记真正放大受到伤害 +20% (原版 JS 和 PoC 都没消费过)
- 净化 q_cleanse 清除治疗削减
- q_swift CD-1 / q_critdmg +25% 爆伤 (两个原死 buff)
- 宝箱龟「星辉」装备 (所有伤害转真伤) — 原 case 标签错配完全失效, 已修
- 海浪扫向 (横排 3 张 vs 竖列 2 张)
- 龙蛋首次喷火 (原 600ms 后被 noop 桩重置, 推迟到 turn 3)
- 龙蛋 / 珍珠火球触发 on-hit 链 (火珊瑚 / 冰封水母 / 吸血 / 雷电法杖充能)
- 生命珍珠回血走 applyHeal (响应潮汐涟漪/治疗削减/守护羁绊)
- FPGA-10 / 信号放大器: 用独立"增伤"概念 `_dmgBonusThisTurnPct` 乘所有伤害, 不再只 ATK 加成
- DoT 颜色按伤害类型 (灼烧/中毒=魔法蓝, 流血=物理红, 诅咒=真伤白)
- 装备 proc 伤害飘字清理 emoji (蜡烛/哑铃/飞镖/左轮/海浪/迷你水晶/玩偶熊/宝箱连锁)
- 宝箱龟生命偷取面板显示双计 (vamp+crown 显 80% 实为 40%)
