- brief：竹叶龟每隔一回合进行蓄力充能。拥有充能时，释放技能会消耗充能从而追加一发强化攻击造成 63 魔法伤害，回复 33最大生命值，并永久增加 24 最大生命值。

    造成（75%×攻击力(40) + 8%×最大生命值(418) = 63）魔法伤害。
    回复（8%×最大生命值(418) = 33）生命值。
    永久增加（60%×攻击力(40) = 24）最大生命值。
    已通过被动累计获得 0 最大生命值
    
    深海闯关下，生长提供的最大生命值不会在每关被重置

- brief：竹叶龟对目标甩出3片叶刃，造成共（100）物理伤害
- detail：竹叶龟对目标甩出3片叶刃。

    共（100）物理伤害。

- detail：竹叶龟为自己回复（10%×最大生命值(418) = 42）生命值。
    为存活队友施加（12%×最大生命值(418) = 50）护盾，持续3回合。

    冰寒效果为减少目标20%攻击力

**强化生长**（被动）
- brief：竹叶龟充能强化：转而造成 94 魔法伤害，回复 50 最大生命值，并永久增加 42 最大生命值。

**竹刺阵**（cd5/5段/aoe）
- brief：竹叶龟召唤竹刺从地面刺出，对全体敌方刺击五段，造成共（99）物理伤害
