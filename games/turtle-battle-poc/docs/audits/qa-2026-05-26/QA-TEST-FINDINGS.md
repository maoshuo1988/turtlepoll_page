> **核心方法学注意（影响数字判读）：**
> 1. 审计 dummy = **0 防/0 抗 + 1,000,000 HP**（`skill-audit.ts:38`）。所以凡是带「%目标最大/当前生命值」「%自身生命值」的技能，绝对数字会爆表（8%→80000、20%→200000、26%→260000）。**这是 dummy 高血量造成的，不是 bug**；公式本身正确（如熔岩弹 80040 = 40 攻击基础 + 80000 = 8%×1M）。
> 2. 审计开 `_auditMode` 让动画 sleep 瞬返，逻辑层完整但**视觉/时序问题测不到**。
> 3. 事件驱动被动（死亡复活/击杀/闪避/登场召唤/回合制）在孤立审计里**不触发**，显示「无变化」属正常，需实战验。

## 一、技能（28 龟 × 全部主动技能）

**总体：绝大多数技能伤害/层数/buff/命中数与描述一致。** 逐条核对结论：

### 🔴 需重点跟进
| 龟 | 技能 | 现象 | 判断 |
|----|------|------|------|
| 闪电 | **闪电打击** | 描述「共 115%攻击力 = {M:0.23×ATK×5}」≈52，**实测总伤仅 ~10（=23%ATK）** | **确认：描述与实装差 5 倍。** 已查 handler `skill-handlers.ts:2745-2746`：`perHit = atk×atkScale/hits`，即 atkScale(0.23) 是**5 段的总量**而非每段；5 段合计 = 23%ATK ≈10。P79 注释明确「之前没除→5x 伤害 bug」，按 JS lightning.js:5 修成除以 hits。**所以 handler 是对的（23% 总量），描述 token 错了**：应改 `{M:0.23*ATK}`、文案「共 23%攻击力」（≈10），而非 ×5。⚠️ 这条错误 token 本次回炉时被我沿用了，需修。 |
| — | （对照）雷暴 | 描述「共 220% = {M:0.11×ATK×20}」 | **正确**：barrage handler `:2785` 每段 = atk×0.11**不除** hits，20 段合计 220%。与闪电打击的「除/不除」不一致是设计差异，描述需各自匹配。 |

## 四、羁绊 / 协同（10 标签 × tier2/tier3）

定义集中在 `synergies.ts`，激活逻辑正确（计阵容 tags：≥3→tier3，≥2→tier2）。**但多条效果只 set flag、从未被消费（dead/stub）——描述与实装不符，这是本轮最大发现：**

### 🔴 完全未实装（描述写了但不生效）
| 羁绊 | 未实装效果 | flag（0 处消费） |
|------|-----------|------------------|
| **换形 tier2+tier3** | 换形后 5%/10% maxHP 护盾 **整个没实装** | `_synergyShiftShieldPct` |
| **换形 tier3** | 首次换形 +8% ATK 永久 | `_synergyShiftFirstAtkBonus` |
| **运气 tier2** | 第1回合给 1 随机消耗品 | `_synergyLuckGrantConsumable` |
| **运气 tier3** | 第1回合给 1 装备 + 1 消耗品 | `_synergyLuckGrantEquip`(+consumable) |
| **财富 tier3** | 商店 -25% 价 | `_synergyWealthShopDiscount` |
| **再生 tier3** | 复活时对随机敌 1×ATK 魔法 | `_synergyRegenReviveAttack` |

> 代码注释（synergies.ts:21-23）已自认「运气 grant 在 JS/PoC 均 stub，仅闪避实际生效」——即沿袭旧版未实装。换形护盾两条 flag 全 0 消费，等于**换形羁绊目前只有「显示」没有「效果」**。

### ✅ 已实装生效
- 物理(ATK +4/8% + tier3 流血)、法术(法穿 +2/5 + tier3 敌魔抗-4)、守护(护盾/治疗放大 +5/10% + 登场盾，3 处消费)、元素(元素伤 +5/10% + tier3 灼烧 tick)、刺杀(暴击/穿甲/击杀/tier3 处决)、召唤(召唤物 HP/ATK 加成)、财富(每回合 +4 深海币)、再生(复活 +15/25% HP)。

### 建议
1. 决定**换形羁绊**：要么实装护盾（在 lava/two_head 变身处读 `_synergyShiftShieldPct`），要么改描述为实际效果，**不能留空描述**。
2. 运气物品发放 / 财富 tier3 折扣 / 再生 tier3 复活攻击：同样「实装 or 改描述」二选一。
3. 这些是「描述与实装不符」类问题，建议优先于其它，避免误导玩家。
