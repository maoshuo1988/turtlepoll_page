## 🔴 P1 — 生命偷取 `_lifestealPct` 整条死链 ✅已修(2026-05-29, 见 LEDGER #10)
**现象**: 有两套生命偷取字段, 单位不同, 没打通:
- `lifestealPct` (无下划线, 小数 0.10=10%) — `recalcStats` 从 buff 算出, **通用 on-hit 消费** (passive-triggers.ts:600)。✅工作。
- `_lifestealPct` (有下划线, 百分点 10=10%) — 永久/装备类来源写它, **但通用 on-hit 不读它**, `recalcStats` 也不把它折进 `lifestealPct`。→ **只有装了 e_star(海星) 的龟在 equipment-runtime.ts:78 才消费**, 其余全是死的。

**受影响 (这些"生命偷取"实战不回血, 但面板照显)**:
- 赌神·命运之轮 ♣梅花 +4%/层 (BattleScene.ts:5339)
- 猎人·猎杀 击杀 +8% (BattleScene.ts:4554, 且 DetailPanel:895 把它显示出来 → 显示了不存在的吸血)
- 王冠 loot crown +15% (BattleScene.ts:4650)
- e_fpga 装备 +12% (equipment.ts:96)
- b_vamp 奖励 +8% / 嗜血药剂 quick-shop +15% (BattleScene.ts:4643 / 1139)

**根因**: `recalcStats` (stats-recalc.ts:76-77) 算 `lifestealPct = _baseLifesteal + buff加成`, 从不读 `_lifestealPct`。
**推荐修**: `recalcStats` 把 `+ (_lifestealPct ?? 0)/100` 折进 `lifestealPct`。
**为什么要你定**: (1) 一次性激活一大批此前"白写"的吸血 = 全局平衡变动 (赌神/猎人/王冠/FPGA 等会突然变强很多)。(2) e_star 既走自己的 onHit(溢出转盾)又会被通用 on-hit 二次吸 → 要么 e_star 改用专属字段, 要么通用消费排除 e_star。
**注**: BattleScene:1139 `_lifestealPct += b.value*100` 看着单位也可疑(若 b.value=15 → +1500), 一并核。

## 🔴 P2 — 无头·灵魂打击 (headlessSoulStrike) 魔法伤害不吃魔抗 + 不暴击
**现象**: 描述 "（90%ATK）+ 20%目标当前生命值 **魔法伤害**" (pets.ts:3430), 但 handler (skill-handlers.ts:5313-5321) 直接 `applyRawDamage(totalDmg,'magic')`, **没过 `calcDmgMult(calcEffMr)`、也没 rollCrit**。
**对比**: 它的物理姊妹技 灵魂收割(soulReap, :5347-5350) 正确地 `calcDmgMult(calcEffArmor)`+暴击; 全文件 ~30 个手算技能都吃魔抗/护甲。**全场仅此一个"纯魔法核伤却跳魔抗"的离群点** (泡沫释放 :3482 跳魔抗是设计内 = 储能释放, 非核伤)。
**推荐修**: 按描述"魔法伤害"对齐 — 加 `calcDmgMult(calcEffMr)` + rollCrit (同 soulReap/dealMagic)。
**为什么要你定**: 这是**削弱** (高魔抗目标会少吃伤)。且"灵魂/%当前血"是否设计成无视魔抗(主题穿透)有歧义 —— 描述没写"无视魔抗", 但 %当前血伤害常被设计成免减伤。

## ⚠️ P7 — 永久盾类 ✅已实装(2026-05-29, 见 LEDGER #17/#18): 凤凰熔岩盾+缩头盾改特殊限时4回合池, 描述本就对、代码对齐
全表扫了一遍含"护盾...持续N回合"的技能。**单纯防御盾**(祝福/坚不可摧/万能牌)已是"永久护盾"措辞 ✅。剩两只是**永久盾 + 耦合机制**, 你的默认("改永久+改描述")不能干净套用, 因为耦合那部分有平衡决策:

- **凤凰·熔岩盾 (phoenixShield, skill-handlers.ts:2049)**: 代码 `caster.shield += amt` = **永久盾**, 但 counter(反击)是 4 回合 buff。描述(pets.ts:2417)"获得熔岩护盾, 持续4回合。**护盾存在时**反击"。冲突: 盾永久 → "护盾存在时"=永久反击, 但代码反击只 4 回合。**要你定**: (A) 盾永久+反击4回合(=当前码, 改描述为"4回合内反击"); (B) 盾永久+反击也永久(=贴合"护盾存在时", 但凤凰大增强, 要改码)。
- **缩头·防御 (hidingDefend, skill-handlers.ts:3880)**: 代码 `caster.shield += amt` = **永久盾**, 4回合后 hidingShield buff 到期 → 回 `剩余护盾×20%` 生命 **但护盾保留不消耗** (BattleScene.ts:5074)。描述(pets.ts:3287)"护盾持续四回合, 到期时将剩余护盾的20%**转化为**生命"。冲突: 盾永久不消失, "转化"实为"额外回血+盾还在"。**要你定**: 措辞改"永久护盾, 4回合后额外回复剩余护盾20%的生命(护盾保留)" 是否OK; 还是要真做成"到期消耗护盾转血"。
