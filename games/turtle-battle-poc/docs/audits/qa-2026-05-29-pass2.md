## 🔴 高优先 (真 bug, 玩家可见)

1. **debuff-num 黑字 (跨多龟) ✅已核实** — `debuff-num` 不在 FloatCls 类型/FLOAT_STYLE/index.html CSS → 黑字不可见。7处 `api.floatNum(...,'debuff-num')`: skill-handlers 1322(神罚偷甲抗) / 2565(竹击冰寒) / 2746(猎杀印记) / 3648(冰封眩晕) / 4645(眩晕) / 4986(中毒☠) / 5830(恐惧!)。修: 加 CSS+类型+FLOAT_STYLE/ROW，或全改 debuff-label。**[问: 统一橙色 还是 各保留原色(冰寒青/中毒紫…)?]**

2. **headless 恐惧=整回合跳过 ✅已核实** — BattleScene:2146-2166 把 fear 和 stun 一起处理: 整回合禁手 + 立即清 fear buff + 飘字/日志误标"💫眩晕跳过"。应是 -20%伤害/3回合(damage.ts:73-75 减伤因 buff 秒清几乎永不生效)。修: fear 不跳回合不清, 只 stun 跳。

3. **ghost 诅咒 无状态徽章 ✅已核实** — buildStatusHtml 只有 case 'dot'(老类型), curse 推的是 type 'curse' → 无徽章。怨灵/灵魂风暴/强化死亡诅咒 全程不可见(仅每回合紫DoT飘字)。修: 加 case 'curse'。

4. **ghost 幽冥突袭 + 灵魂风暴(魔法段) 双重暴击 ⚠️** — base 预乘 critMult 后又传 dealMagic(内部再 rollCrit+critMult) → 暴击翻倍两次; 飘字硬编 magic-dmg → 暴击不显蓝大字。skill-handlers ~1377/1410, 1463/1478。修: 别预乘, crit 透传, 飘 crit-magic。

5. **cyber 机甲变身漏 _isMech ⚠️** — BattleScene:4455-4530 没设 `dead._isMech=true`(JS state.js:257有) → 机甲不自动攻击, 反成玩家可控(每回合手动指挥); 技能 type 给 physical 非 mechAttack。修: 设 _isMech + type mechAttack。

6. **crystal 结晶层数完全不可见 ⚠️** — _crystallize 累在敌人身上, 被动卡读自己的(永远0), 敌人无徽章 → 满4层引爆零可见。+ 引爆飘字 `-N💎` 色 #c77dff 未映射 → 推断成 direct-dmg(红) + 误触受击闪。修: 加 _crystallize 敌方徽章 + 引爆飘字显式 magic-dmg。

7. **space 扭曲空间换位无视觉 ⚠️** — starGravityWarp emit 'star-gravity-warp' 但**无监听器** → 数据换位但 sprite 不动。招牌效果看不见。修: BattleScene 加监听重新 tween 各 view 到新位。

8. **ghost 虚化(physImmune) 无徽章 ⚠️** — 无 case 'physImmune' → 看不到虚化中/剩余回合。

9. **headless 灵魂打击 魔法暴击显红 ⚠️** — skill-handlers:5362 暴击用 crit-dmg(红物理色), 应 crit-magic(蓝)。

10. **chest 寻宝直觉 面板财宝阈值错 ⚠️** — buildChestPassive 读固定 thresholds, 不读 _chestIntuition 调整后的 → 显示错阈值/进度。
