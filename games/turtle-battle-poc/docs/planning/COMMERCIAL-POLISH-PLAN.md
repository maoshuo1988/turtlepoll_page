# 龟龟对战 — 商业质感改造方案（定稿）

> 目标：网页版（不上 Steam），但要有**正式商业游戏的质感**——玩家打开即觉得是成品而非原型。
> 注：本作是**回合制**游戏（非自走棋），战斗速度维持 1x、不加快进。

## 全局决策（已定）

| 项 | 定案 |
|---|---|
| 对外名字 | 沿用「龟龟对战」，去掉 PoC/Phaser 字样 |
| 战斗速度 | 不动（回合制，不加快进/倍速） |
| 音频来源 | 我用 CC0 免费音源接一套占位，你后续可换正式 |
| 占位美术 | 我先生成像素占位图替 emoji，你后续可换正式 |
| 存档 | 轻量：只持久化 设置 + 成就（localStorage） |
| 新手引导 | 完整 FTUE（第一局手把手；**文案待你给**） |
| 语言 | 中文 only（不做 i18n 框架） |
| 结算画面 | 现状小修（战利品弹出动效 + 音效） |
| 开发按钮（🛠调试/🐛反馈） | 保留但移到不显眼角落 |
| 场景转场 | 深海主题（水波/气泡/海浪过场） |
| 标题/加载页 | logo 动效 + 背景动画 + 加载进度条（独立标题页） |
| 手感 juice | 明显打击感（hit-stop + 震屏 + 粒子） |
| 字体 | 打包**开源像素中文字体**（Fusion Pixel / Zpix 等），中英统一像素风、跨设备一致（替掉未打包的系统 YaHei） |
| 环境粒子 | 按场景加氛围粒子（樱花飘瓣 / 深海气泡光束 / 废墟尘埃） |
| 角色阴影 | 已有脚底阴影，做质量打磨（软阴影 + 击飞时随高度缩放） |
| 锦上添花（全要，标 ✨） | 自定义光标(阶段0) / 关卡过场卡 + 调色后处理(阶段1) / 数字计数动画 + 死亡演出(阶段3) |

## 阶段 0 ｜清开发痕迹 + 品牌 + 字体（我自主，~1 天）
- 全局去 `PoC` / `Phaser` 字样：启动 splash、主菜单条目「龟龟对战 PoC (Phaser)」、任何标题
- 启动黑屏 → 正式**标题/加载页**：logo 弹入+呼吸 + 深海背景动画 + 资源加载进度条（现 104MB 直接黑屏等）
- 🛠 调试 / 🐛 反馈(F11) 缩小并挪到不显眼角落
- **字体统一**：打包开源像素中文字体（Fusion Pixel / Zpix），`@font-face` 全局替掉 m6x11+YaHei 混搭 →
  中英统一像素风 + 跨设备一致（YaHei 是 Windows 系统字、没打包 → Mac/Linux 现在会变字）
- emoji 占位（糖果炸弹 🍬💣 纹理、调试键等）→ 列「待生成像素图」清单
- ✨**自定义鼠标光标**：贴主题光标（小气泡/龟爪），全局 CSS cursor（轻量）

## 阶段 1 ｜深海转场 + 环境粒子 + 结算小修（我自主，~2 天）
- 统一**转场工具**：菜单↔战斗↔结算 用水波/气泡/海浪过场替换硬切
- **环境粒子**：按场景加氛围——樱花飘瓣（樱花场）/ 深海气泡+光束（深海场）/ 尘埃（废墟场），战场不再死板
- 加载页进度条（预载 104MB）
- ✨**关卡过场卡**：进战斗前一张「第 N 关 / 对手介绍」卡片(滑入+停留+滑出)，给开场仪式感
- ✨**调色/后处理**（成本较高）：Phaser WebGL post-pipeline 全局色调统一 + 暗角 + 轻 bloom，氛围拉满
- `BattleEndScene` 小修：战利品逐个弹出动效 + 胜负 stinger（音效挂阶段 2）

## 阶段 2 ｜音频（我自主接框架 + CC0 占位，~1–2 天）

## 阶段 3 ｜手感 juice — 明显打击感（我自主，~2 天）
- **hit-stop**：大伤害/暴击命中瞬间微停
- **震屏分级**：按伤害量明显但不晕
- **伤害数字**：带重量感弹出 + 暴击放大 + 颜色分层
- 命中闪白/顿挫 + 粒子统一
- **角色阴影质量**：已有脚底阴影 → 软化 + 击飞/跳跃时随高度缩放（离地变小变淡）
- ✨**数字计数动画**：深海币/HP 变化滚动跳数（而非瞬切），HP 条平滑 tween
- ✨**死亡演出**：角色阵亡溶解/碎裂 + 短慢镜，而非直接消失
- UI 按钮按下凹陷 + 悬停发光（补全未覆盖处）
