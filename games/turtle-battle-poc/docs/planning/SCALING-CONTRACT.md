# 缩放 / 背景 契约 (单一真相源)

> 任何分辨率 / 黑边 / 闪屏 / 背景问题，**先查这份文档**，按它改；不要再"出一个症状打一个补丁"。
> 这份契约存在的原因：历史上分辨率/背景被 5 套机制反复打补丁（FIT↔ENVELOP、zoom=DPR、CSS tile、in-canvas bg、per-scene 类切换），互相叠、互相冲突（菜单 tile 甚至被画两遍、漂移速度还不一样）。现在收敛成一套。

---

## 为什么网页游戏会有这问题、Steam(原生) 没有

原生游戏的画面底下**没有网页**：引擎独占整个窗口、每帧把后备缓冲（含黑边）一次性画满，底下没有任何东西能露出来 → "闪屏 / 黑边露出网页" 这一整类 bug 在原生世界不存在。
我们在浏览器里，多了一项原生没有的本钱：**CSS 能以设备真实分辨率画静态背景**。而 Phaser 画布在 `Scale.FIT` 下只渲染 1280×720、再被浏览器上采样到屏宽 → 画布内的东西天然比 CSS 软。
所以**正确分工**：静态平铺背景交给 CSS（设备分辨率、最锐）；画布只画会动的 UI/精灵/战斗。闪屏防护不靠"给画布盖不透明底"，而靠"背景这层 CSS 从不消失 + 战斗相机不透明覆盖"。

## 唯一契约 (三层，各管各的，互不重叠)

### 1. 设计分辨率 = 1280×720，缩放模式按场景
- **菜单系所有场景 = `Scale.FIT`**：等比完整显示，UI 永不被裁。代价是出现 letterbox 黑边（背景由第 2 层统一填）。
- **`BattleScene` = `Scale.ENVELOP`**（仅它，create 时切、shutdown 切回 FIT）：左右填满、牺牲上下裁切，战场更沉浸。
- DPR 上限 3；文字 `setResolution(max(DPR,2))` 单独保清晰，与画布 zoom 无关，**zoom 必须 = 1**（zoom=DPR 会把 canvas CSS 尺寸钉死、高分屏覆盖不到，历史已坑过）。
- **画布透明** (`main.ts: transparent: true`)：让背景 CSS 透出。

### 2. 菜单背景 = **唯一一层 CSS 海 tile**，透过透明画布显示（中心+黑边同一层 → 处处一样锐利）
- `html.menu-bg-active::before/::after`：海 tile `background-size:512px` + `menuBgDrift 25s` 右下漂移 + 压暗渐变。设备分辨率渲染，**不经画布上采样 → 锐利**。
- 菜单各场景相机**透明**(默认) → 整屏（中心设计区 + 四周黑边）都显示这同一层 CSS，**没有"中心软/四周锐"的割裂**。
- **不要在画布内再画一层平铺背景**（曾用 `BackgroundScene` tileSprite，被 1280 画布上采样到屏宽 → 用户报"四周清晰中间糊"。已删除）。
- 贴图 `menu/menu-bg-tile.png` 已降到 **512×512**（= 显示尺寸，1:1 最锐；原 1946×1984 备份为 `menu-bg-tile.orig-1946.png`）。

### 3. 战斗 / 结算背景 = **Phaser 画布内画 + 相机不透明**
- 会动、要随相机缩放，必须画布内渲染。`BattleScene` 自己画地图，相机 `setBackgroundColor('#0a1726')` **不透明** → 盖住身后菜单绿 tile，切 ENVELOP 那帧也不露绿。`BattleEndScene` 同。
- 战斗黑边 = `html.battle-active body::before/::after`：干净深海径向渐变 + 金边暗角（用户明确要"深色画框"）。

## 闪屏为什么不会再有
- **菜单↔菜单**：背景是同一层 CSS（从不消失/从不切换）→ 切场景时背景纹丝不动，零闪。
- **进/出战斗**：战斗相机不透明、立刻盖住中心；黑边由 `battle-active` 切深色。绿 tile 不会透出。
- **转场蓝闪**：曾经的全局 `fadeIn(280,6,16,30)` 已删（它本身就是那道蓝）。

## 改这块前的红线
1. **不要在画布内画静态平铺背景** —— 一定比 CSS 软（画布只有 1280×720 再上采样）。静态背景永远交 CSS。
2. **不要给画布加不透明底色去"防闪"** —— 那会盖住 CSS 背景、让中心发软（历史教训）。防闪靠"背景 CSS 不消失 + 战斗相机不透明"。
3. **不要再加全局转场 `fadeIn`** —— 那层淡入本身就是用户看到的闪。
4. 菜单海 tile 改观感 → 改 `html.menu-bg-active::before`（`background-size` / `menuBgDrift` / `menu-bg-tile.png`）。战斗黑边改 `html.battle-active body::before/::after`。
5. 加新场景：菜单类 → 什么都不用做（相机默认透明，自动透出 CSS 海；记得 `classList.add('menu-bg-active')`）；战斗类全屏沉浸 → 仿 BattleScene 设不透明相机底色 + ENVELOP + `battle-active`。
