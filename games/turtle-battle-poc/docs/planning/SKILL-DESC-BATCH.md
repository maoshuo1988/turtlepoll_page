# 技能描述批改 — 第一批 10 只龟

> 用法：直接在本文件里改 `brief`(简述, 局内技能卡) 和 `detail`(详情, 长按/图鉴) 的文字。
> 改完告诉我，我按 organize→wire→sync 写回 `pets.ts`。`（填值）`占位写上我来算。

## 模板变量速查
- 颜色占位（自动上色 + 计算）：`{N:表达式}`=物理红 · `{M:}`=魔法蓝 · `{T:}`=真实白 · `{S:}`=护盾灰 · `{H:}`=治疗绿 · `{D:}`=护甲黄 · `{P:}`=穿甲 · `{B:}`=纯数字标注 · `{表达式}`=无色
- 变量：`ATK` `DEF` `MR` `HP`(=最大生命) `LV`(等级) `crit`，以及技能专属（`goldCoins` `hunterKills` 等）
- 手写颜色：`<span class="val-atk">橙</span>` `val-heal`绿 `val-def`黄 `val-magic` `val-pierce`
- 灰色注释：`<span style="color:#888">…</span>`

- **detail**：糖果炸弹（被动）。\n\n登场时召唤一只糖果炸弹：\n· 最大生命值 = 糖果龟登场时最大HP × <span class="val-atk">40%</span>\n· <span class="val-atk">0</span> 攻击力 / <span class="val-atk">0</span> 护甲 / <span class="val-atk">0</span> 魔抗\n· 不会主动攻击\n\n每回合开始时自损 <span class="val-pierce">20% 自身最大HP</span>。\n\n死亡（自损死或被打死都算）时爆炸：\n对全体敌方造成总计 <span class="val-magic">150% 自身最大HP</span> 的魔法伤害，由所有存活敌人均摊（每只受 总伤害 / 存活敌人数）。\n\n召唤格子可在选龟界面拖动调整；糖果龟阵亡 → 糖果炸弹立即引爆。
