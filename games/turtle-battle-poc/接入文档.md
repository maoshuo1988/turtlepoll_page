# 斗龟场 v1.0 接入文档

## 三步接入

### 1. 解压

把 `turtle-v1.0.zip` 解压到你站点服务器任意子目录，例如：

```
你的网站根目录/games/turtle/
```

解压后里面就是 `index.html` + 资源文件，**纯静态、零依赖**（不需要 Node / 后端 / API）。

### 2. 在你的页面里嵌入 iframe

```html
<iframe
  src="/games/turtle/"
  width="1280" height="720"
  style="border:0; display:block; margin:0 auto;"
  allow="fullscreen; autoplay"
  allowfullscreen
  title="斗龟场"
></iframe>
```

**注意**：`src` 路径**末尾斜杠必须有**（`/games/turtle/` 不是 `/games/turtle`），否则相对路径会算错。

### 3. 完事

打开你的页面就能看到游戏。
